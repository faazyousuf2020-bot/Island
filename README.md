# Faaz Island

A Dynamic-Island style pill that sits around the front camera on Android.

## What it does
- **Idle** – a small black pill hugging the camera (optional googly eyes that look around and blink)
- **Notifications** – pops open with the app icon, title and message; tap to open
- **Music** – album art + dancing bars while playing; tap for play/pause/next/previous
- **Charging** – green bolt + battery filling animation when you plug in
- **Big view** (tap) – clock, date, battery, torch toggle, +1/+5 min timers
- **Timer** – live countdown ring in the pill; vibrates when done

## Build
Push to GitHub → Actions builds it → download `FaazIsland.apk` from **Releases**.

## Setup on phone
1. Install the APK and open **Faaz Island**
2. Step 1: Accessibility → Faaz Island → On
3. Step 2: Notification access → Faaz Island → Allow
4. If either is greyed out: App info → ⋮ → Allow restricted settings
5. Use the sliders to fit the pill over your camera
